1. Project Background

The Singapore Real Estate Intelligence Platform helps a Singapore real estate agency make better pricing, rental, and customer-targeting decisions using ML. This workstream focuses on predicting monthly condominium rental prices and identifying key pricing factors.

Dataset: CondoRental.csv — 10,000 URA Executive Condominium rental transactions (postal districts 18–28), enriched with GPS coordinates and amenity distances via Singapore's OneMap API.

Success Criteria: Materially lower MAE/RMSE than a naive district-average baseline, with an interpretable feature-importance ranking the agency can act on.

2. Work Accomplished

Data Preparation

  • Cleaned currency strings, banded floor-area ranges, and abbreviated lease dates.
  • Imputed 3 missing bedroom values (0.03%) using median within matching floor-area bands.
  • Flagged rent outliers via 1.5×IQR rule — retained as genuine premium transactions.
  • Enriched via OneMap API: GPS coordinates, MRT/supermarket/school distances, true building age.

Modelling

  • Compared Linear Regression, Random Forest, and XGBoost pipelines.
  • Validated via 5-fold cross-validation, not just a single train-test split.
  • Tuned all three model families via GridSearchCV before final selection.

3. Recommendation and Analysis

Key Finding: Unit size (bedroom count) dominates rent prediction, accounting for roughly three-quarters of total feature importance. Location-convenience features contribute a secondary signal.

StakeholderRecommendation
LandlordsAnchor asking rent to predicted rent ± MAE band ($456), not gut feel.
AgenciesScreen listings pre-publication; flag rents outside the MAE band.
TenantsBenchmark quoted rent against district-summary table for negotiation leverage.

Limitation: R² = 0.352 reflects genuine data constraints (weak correlations, URA privacy banding, missing unit-quality signals) — predictions are directional guidance, not precise valuations.
